# הרצאות 1–2 (26.10, 29.10) — וקטורים, מכפלות, ישרים ומישורים ב-Rⁿ / R³

מקור: סריקות כתב יד (`הרצאה 1`, `הרצאה 2`). הנוסחאות נקראו ישירות מהתמונות. **טקסט הניסוח בעברית בכתב היד לא היה קריא בבירור**, ולכן ההגדרות והמשפטים מנוסחים כאן מחדש לפי הנוסחאות וההקשר. מקומות שלא ברורים מסומנים `[לא קריא]`.

## הרצאה 1

**פונקציות בכמה משתנים:** F: D ⊆ Rⁿ → Rᵐ. דוגמאות בכתב היד: שטח (מלבן, ...), נפח גליל (רדיוס, גובה), נפח (...). `[פרטי הדוגמאות לא קריאים]`

**Rⁿ = {x = (x₁,…,xₙ) | xᵢ ∈ R}.** נקודה אפשר לראות כנקודה או כווקטור u = OA (מהראשית אל A).

**פעולות על וקטורים (ב-R² / R³):** כפל בסקלר c·v (c>0 באותו כיוון, c=0 וקטור האפס, c<0 בכיוון הפוך, האורך מוכפל ב-|c|); סכום u+v; הפרש u−v. וקטורי הבסיס ב-R³: i=(1,0,0), j=(0,1,0), k=(0,0,1).

**הקבלה / קולינאריות:** u,v ∈ Rⁿ מקבילים אם u = m·v או v = λ·u. שקול: rank של המטריצה שורותיה u,v קטן מ-2. וקטורים v₁,…,vₖ הם קו-לינאריים אם הם נמצאים על ישר אחד, כלומר rank ≤ ... `[לא קריא במדויק]`. (נראה שהמשפט: ישר הוא {A + t·u | t ∈ R}.)

**מכפלה סקלרית:** u·v = ⟨u,v⟩ = Σ aᵢbᵢ. תכונות: סימטריה (u·v = v·u), בילינאריות (u·(av+bw) = a u·v + b u·w), חיוביות (u·u ≥ 0, ושוויון אם ורק אם u=0).

**הגדרות:** u ⊥ v אם u·v = 0; נורמה ‖u‖ = √(u·u); מרחק d(A,B) = ‖A−B‖.

**תכונות המרחק / נורמה:**
1. d(A,B) = d(B,A); d(A,B) ≥ 0 ושוויון אם ורק אם A=B.
2. פיתגורס: ‖u+v‖² = ‖u‖² + ‖v‖² אם ורק אם u ⊥ v.
3. קושי–שוורץ: |u·v| ≤ ‖u‖‖v‖.
4. אי-שוויון המשולש: ‖u+v‖ ≤ ‖u‖ + ‖v‖.

**היטל:** ההיטל של v על u הוא v_u = t·u, כאשר (v − v_u) ⊥ u. מכאן t = (v,u)/(u,u), ולכן v_u = ((v,u)/(u,u))·u, ו-‖v_u‖ = |(v,u)|/‖u‖. הזווית θ בין u ל-v: cos θ = |(v,u)|/(‖u‖‖v‖) (בכתב היד הזווית מוגדרת עם ערך מוחלט, כלומר θ = arccos(|(u,v)|/(‖u‖‖v‖)) ∈ [0, π/2]`[לוודא בכתב היד]`).

**ישרים ומישורים (עמוד 2):** ax+by=c ישר ב-R²; ax+by+cz=d מישור ב-R³; Ax=d מערכת משוואות לינאריות, פתרון = A+sp{u₁…uₖ}. ישר: L = {A+tu | t∈R}. דוגמאות: L = {(1,1)+t(1,1)} = {(x,y) | x−y=−1}; ישר דרך (0,1),(1,3): y=2x+1; מישור דרך שלוש נקודות A(1,2,4), B(0,1,1), C(2,1,3): H = {C + tu + sv}.

## הרצאה 2

**מישורים ב-R³:** H = {A + tu + sv | t,s ∈ R}, עם u,v בלתי תלויים. הצגה כמשוואה: H = {(x,y,z): ax+by+cz=d}, והווקטור N = (a,b,c) ≠ 0 הוא **נורמל** למישור, ניצב לכל וקטור במישור (הוכחה: אם x,y ∈ H אז N·(x−y)=0). הכללה: היפר-מישור ב-Rⁿ: a₁x₁+…+aₙxₙ = d. מסקנה: H = {x ∈ R³ : N·(x−A) = 0}, מישור דרך A עם נורמל N.

**מכפלה וקטורית ב-R³:** u×v = דטרמיננטה (i j k; a₁ a₂ a₃; b₁ b₂ b₃) = (a₂b₃−b₂a₃)i − (a₁b₃−b₁a₃)j + (a₁b₂−b₁a₂)k. תכונות:
1. ‖u×v‖ = ‖u‖‖v‖ sin θ = שטח המקבילית הנפרשת על ידי u,v (הוכחה בעזרת sin²θ = 1−cos²θ ושוויון לגראנז': ‖u‖²‖v‖² sin²θ = ‖u‖²‖v‖² − (u·v)² = ‖u×v‖²).
2. u×v ניצב ל-u ול-v, והכיוון לפי כלל יד ימין.
3. u×v = 0 אם ורק אם u,v מקבילים.

**אלגברה:** u×v = −v×u; פילוג על חיבור; (λu)×v = u×(λv) = λ(u×v).

**דוגמה:** מישור דרך A(1,2,3), B(0,1,2), C(−1,1,3). u = B−A = (−1,−1,−1), v = C−A = (−2,−1,0), N = u×v = (−1, 2, −1), המישור: −x+2y−z = 0.

**מכפלה מעורבת:** u·(v×w) = דטרמיננטה של המטריצה עם שורות u,v,w. תכונות: |v·(u×w)| = |u·(w×v)| = … ; הערך המוחלט שווה לנפח המקבילון הנפרש על u,v,w (גובה h = ‖u‖|cos α|, בסיס ‖v×w‖). מסקנות: u×v=0 אם ורק אם u,v תלויים; u·(v×w)=0 אם ורק אם u,v,w תלויים (באותו מישור).

**תרגיל:** האם הנקודות A(1,1,1), B(−1,0,2), C(5,−1,3), D(5,1,2) נמצאות באותו מישור? פתרון: u=B−A, v=C−A, w=D−A, בודקים מכפלה מעורבת. `[התשובה לא נכתבה בעמוד]`

**גאומטריה ב-R³:**
- זווית בין שני מישורים: cos α = |N₁·N₂|/(‖N₁‖‖N₂‖). מישורים ניצבים אם N₁·N₂=0, מקבילים אם N₁ = λN₂. דוגמה: x+y+z=1 ו-2x+2y+2z=3 מקבילים (שונים), לעומת x+y+z=1 ו-2x+2y+2z=2 (מתלכדים).
- **מרחק נקודה ממישור:** המרחק של M₀(x₀,y₀,z₀) ממישור ax+by+cz=d הוא r = |ax₀+by₀+cz₀−d| / √(a²+b²+c²). הוכחה: ההיטל של M₀−M₁ על N.
- **מרחק נקודה מישר** A+tv: r = ‖AM×v‖/‖v‖ (שטח מקבילית חלקי בסיס). דוגמה: המרחק של M(1,−1,3) מהישר (x+1)/2 = (y−2)/(−1) = (z−1)/3, נקודה A(−1,2,1), v=(2,−1,3), AM=(2,−3,2), r = √69/√14.
- זווית בין ישרים: cos θ = |u·v|/(‖u‖‖v‖).
- זווית בין ישר למישור: cos β = |v·N|/(‖v‖‖N‖) = sin α, כאשר α הזווית בין הישר למישור (β הזווית בין הישר לנורמל).
